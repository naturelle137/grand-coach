# Implementation status and next work

The playable desktop app includes the rule engine, series and score sheet,
Classic strength levels and special tables, German and English card and coach
views, six lessons, an optional learning focus and a debriefing of up to three
decisions, an optional counting aid and counting questions. God Mode exposes
the deal to the player and coach; an open display shows it to the player only. The debriefing can show the table as it
appeared when the player acted. Platform coverage and release checks are in
[testing.md](testing.md).

Release 1.0 also requires [modern egui #134](https://github.com/naturelle137/grand-coach/issues/134)
to be implemented, independently reviewed, tested and merged through the
protected PR process. Its full acceptance criteria remain authoritative:
the responsive coach-left, table-centre and last-trick/series-right layout
retains the original trick triangle; completed-trick Augen are shown only
while held, exclude an unknown Skat and remain concealed in accessibility
labels and tooltips; bilingual named opponent portraits are deterministic,
fixed to physical seats and use an isolated random stream. The existing M8,
learner and platform gates remain required. The #131 dialogue is not a
prerequisite for #134; Godot animation is outside its scope. The
implementation and its design decisions are recorded in D-72
(`docs/decisions.md`); #134 counts as done only once that work is reviewed
and merged. See the [release test plan](release-test-plan.md) for pending
checks.
