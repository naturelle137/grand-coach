# Third-party files and libraries

Every third-party file (graphic, font, sound, copied code) and every runtime
dependency with a notable licence is recorded here **before** it enters the
repository.

Only the licences listed in
[CONTRIBUTING.md](../CONTRIBUTING.md#allowed-third-party-licences) are
allowed (D-42).

Rust dependencies are listed in their own table below, checked by hand
against `cargo metadata`; an automated licence check is still to be set up.

| File / library | Source (URL) | Author | Licence | Changes |
|----------------|--------------|--------|---------|---------|
| Standard licence texts `tools/notices/licenses/` (MIT, Apache-2.0, BSL-1.0, BSD-3-Clause, MPL-2.0) | <https://spdx.org/licenses/> (MPL-2.0 and BSD-3-Clause from <https://github.com/spdx/license-list-data>) | MIT, BSD-3-Clause: templates; Apache Software Foundation; Boost; Mozilla Foundation | Licence texts, copied verbatim as their terms permit | none; used only where a crate ships no licence file |
| Fonts embedded by egui (`epaint_default_fonts` 0.37): Ubuntu-Light, Hack, Noto Emoji, emoji-icon-font, egui-icons | <https://crates.io/crates/epaint_default_fonts> | Canonical (Ubuntu); Source Foundry (Hack); Google (Noto Emoji); John Slegers (emoji-icon-font) | Ubuntu Font Licence 1.0; MIT with Bitstream Vera licence (Hack); OFL-1.1 (Noto Emoji); MIT (emoji-icon-font and its subset egui-icons) | none; compiled into `grand-coach` via the `default_fonts` feature, not stored in the repository |

The licence texts and copyright notices that must accompany binaries are
collected in [THIRD-PARTY-NOTICES](../THIRD-PARTY-NOTICES), generated by
`tools/notices` (D-43).

The card faces in `assets/cards/`, the opponent caricatures in
`assets/portraits/` and the texts in `assets/i18n/` are our own work
(generated by `tools/cardgen` and `tools/portraitgen` from hand-written
shape rules, without image models, network or third-party drawings, and
written for this project), not third-party files. Like other generated
content they are CC BY-SA 4.0 (`LICENSE-ASSETS`).

Training data and models contain no third-party data either: the
fixture dataset `tools/nn-train/fixtures/selfplay` is generated by
`nn-train generate` from seeded self-play of this project's own engine
and opponents (origin, commit and seeds in its `manifest.json`;
[model guide](learned-models.md#training-data)); like other generated content it is
CC BY-SA 4.0 (`LICENSE-ASSETS`). The trained card-play model
`assets/models/card-play.gcnn` is trained by `nn-train train` and refined by `nn-train rl` on project
self-play only (data hashes, seeds and commits in `card-play.json`, model
card `card-play.md`, [model guide](learned-models.md#shipped-model-and-runtime)); it is
CC BY-SA 4.0 as well.
