# Supported mechanism responses (#13)

## Evidence boundary

Only explicit catalogue answers to conditional Abstich or partner Overtake
questions are classified. Shared analysis proves possible (some permitted
hidden distributions), certain (all), or absent for a supported legal
catalogue question. Empty arbitrary analysis output is not evidence of absence.
The format 4 question, task/version, expected answer and feedback are validated
when recorded or reopened. No evaluator or additional storage is introduced.
The six current mechanism tasks have possible or absent expected answers;
certain is supported by shared analysis and the complete classifier matrix,
but no additional certain-answer training case is claimed here.
Ordinary games and same-deal practice have no such response observations.
Played cards, losses, regret and agreement cannot establish strategic errors,
intentions, mastery or transfer. Counting responses remain separate.

Assistance is an independent, sticky context, never credited as unaided.
Positive/negative/uncertain test expectations are specified independently of
production classification; catalogue boundary cases establish absence rather
than interpreting an arbitrary empty analysis result.

## Aggregation contract

One observed opportunity is (attempt, task ID, version); presentation, help and
settlement never create additional samples. Rows separate mechanism/topic,
task/version, attempt context, assistance, app-local first/repeated/unknown
presentation and unseen-changed eligibility. A complete history establishes
first presentation only inside this file; migrated/reset/missing histories
cannot prove first exposure. A prior recorded presentation proves repetition
even if overall exposure history is incomplete. Outside-app exposure is unknown.

Presented includes unanswered opportunities. Answered includes unsupported
answers; scored includes only supported answers. Skipped is explicit; unknown
is presented minus scored minus skipped (unanswered plus unsupported).
Category counts retain unanswered, skipped and unsupported separately.
Earlier/recent windows use the last 20 settled observations within the exact
same row: ten before the latest ten, in persisted presentation order. Help and
unanswered presentations do not fill windows. Below 20 show a sparse fallback;
empty histories show no mechanism observations. Counts describe response
patterns and possible practice topics, never measured learning improvement.
No cross-context percentages or unseen-outside-app claims are made.

Summaries scan bounded history with hash indexes, using immutable validated
entries, without reconstructing catalogue positions on GUI frames. Existing
format, provenance validation, atomic saves, migration, dedup and reset remain.
